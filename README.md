# Интернет-магазин турагентства ООО «ОрёлТур»

Веб-проект, реализованный на PHP и MySQL.  
Сайт представляет собой интернет-магазин туров с возможностью регистрации пользователей, оформления бронирований и управления данными через административную панель.

# Описание проекта

Проект разработан в рамках учебного задания и реализует функционал интернет-магазина, адаптированного под турагентство.

Пользователь может:
- просматривать туры;
- добавлять туры в избранное;
- добавлять туры в корзину;
- оформлять бронирование;
- просматривать историю заказов.

Администратор может:
- управлять турами;
- управлять направлениями;
- управлять пользователями;
- управлять заказами;
- управлять новостями и акциями.

# Безопасность

В проекте реализованы:
- хеширование паролей (`password_hash`);
- проверка пароля (`password_verify`);
- защита от SQL-инъекций (PDO);
- защита от CSRF-атак;
- валидация данных на стороне клиента и сервера.

# Структура базы данных

Используются следующие таблицы:
- `users` — пользователи;
- `categories` — направления;
- `products` — туры;
- `orders` — заказы (бронирования);
- `order_items` — позиции заказов;
- `news` — новости и акции;
- `company_info` — информация о компании.

# Требования к окружению

Для запуска проекта необходимы:
- Open Server Panel (или аналог);
- PHP 7.4 или выше;
- MySQL / MariaDB;
- phpMyAdmin;
- браузер;
- редактор кода (например, Visual Studio Code).

Открыть phpMyAdmin и выполнить:
```sql

3. Импорт базы данных
